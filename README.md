# # Cinema Management System 🎬

Комплексная база данных для управления сетью кинотеатров, реализованная на SQL Server.

## 📌 О проекте
Этот проект демонстрирует архитектуру базы данных для бронирования билетов, анализа выручки и управления сеансами.

### Основные возможности:
*   **Схема данных:** 5 связанных таблиц с настроенными связями (Primary & Foreign Keys).
*   **Бизнес-логика:** Хранимая процедура `sp_BookTicket` с проверкой доступности мест (защита от дубликатов).
*   **Аналитика:** Сложные SQL-запросы для расчета выручки по фильмам и загруженности залов.

## 🚀 Как использовать
1. Запустите `schema.sql` для создания структуры.
2. Загрузите тестовые данные из `data.sql`.
3. Используйте запросы из `analysis.sql` для получения отчетов.
